To transform your workstation interface into a modern, institutional dark-themed layout like **Signal Sigma** (designed by *K&Z Design*), you need to restructure both the **UI styling/design system** and the **underlying CSS layout architecture**.

Here is a full structural guide and code blueprint to replicate this exact UI style:

---

### 1. Key Design System Attributes

| Visual Element | Signal Sigma Implementation Pattern |
| --- | --- |
| **Color Palette** | **Background:** Obsidian `#111215` / `#16171B`<br>

<br>**Panels/Cards:** Matte Charcoal `#1C1E23`<br>

<br>**Borders:** Subdued Gray `#2A2D35`<br>

<br>**Accents:** Emerald Green `#34D399` (Bullish/Targets), Rose `#F87171` (Bearish), Amber `#FBBF24` (Warning) |
| **Typography** | Low-contrast monospace/sans-serif stack (e.g., *Inter*, *JetBrains Mono*, or *SF Pro Text*) with reduced font weights for tabular data. |
| **Borders & Radius** | Smooth rounded corners (`border-radius: 10px` or `12px`), 1px solid dark borders (`#2A2D35`), subtle box-shadow overlays. |
| **Layout Structure** | 3-Column Grid: **Collapsible Sidebar (Left)** $\rightarrow$ **Main Data/Chart Area (Center)** $\rightarrow$ **Inspector Panel (Right)**. |

---

### 4. Charting Library Recommendation

To render the gradient area charts and stock lines seen in the screenshot:

* **Lightweight Charts by TradingView (`lightweight-charts`)**: Best for financial workstation performance. It supports dark themes natively and handles thousands of data points smoothly.
* **Recharts / Chart.js**: Good for financial overview charts with linear SVG gradients (`linearGradient` with `stopOpacity` decreasing to transparent).

---

### 5. Quick Customization Steps for Your Codebase

1. **Dark Mode Override:** Replace bright gray background (`#f3f4f6` or `#ffffff`) with ultra-dark hex colors (`#111215` main, `#16171B` panels).
2. **Subtle Borders:** Add `1px solid #2a2d35` on card and container borders instead of heavy box shadows.
3. **Move Chart Tools to Side Panels:** Shift global configuration options (e.g., Target Prices, Notes, CAGR calculations) into a right-hand sidebar drawer rather than keeping them inside modals.
